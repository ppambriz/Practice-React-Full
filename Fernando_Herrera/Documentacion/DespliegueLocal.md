##### **Servidor http estático desde una computadora** 



* Instalación del servidor en consola como administrador (por ser global)

npm install --global http-server



* Una vez que se instala, ejecutar el siguiente comando para ver en que puerto local se instalo abrir y actualizar.



&#x20;   http-server -o
